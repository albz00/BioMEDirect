Admin Panel Instructions

BioME Control Panel — quick reference

1 Logging In

  • Sign in with your admin email and password.
  • Check Remember Me if you want to stay signed in on this device.

2 Typical Workflow

  1. Scan All Sections + Lessons — Discovers every lesson from the main menu so you can manage them here.
  2. Refresh Available Videos — Loads the list of videos you can assign to lessons.
  3. Assign or update videos — Select a lesson in the list, pick a video from the dropdown, and click Assign or Update.
  4. Optional: Use Map Segment Links to copy menu labels into the timeline, or Detect Video Titles to auto-fill chapter names from the video.

3 Top Buttons

  • Scan All Sections + Lessons — Refreshes the lesson list from the menu. Do this first so you see all lessons. Lessons missing a video appear at the top.
  • Refresh Available Videos — Updates the video list. Do this before assigning so your dropdown shows all current videos.
  • Map Segment Links — Fills in chapter labels from the lesson menu. Use after you’ve assigned videos.
  • Detect Video Titles (OCR) — Tries to read titles from the video and set chapter names. Best used after scan and video assignment.

4 Working With a Lesson

  • Click a lesson in the sidebar to select it. Use Search to find a lesson by name.
  • Filters: Show All lessons, only Missing (no video), or only Has Video.
  • Change the Section name or Lesson name if you want a different label in the menu, then click Save Lesson Name.
  • Pick a video from the dropdown and click Assign or Update to link that video to the lesson.
  • Open Timeline / srcArray Editor below to view or edit chapter start/end times and titles.

5 Available Videos

This list shows all videos that can be assigned. Expand the section to see it. Click a video to preview it. To attach a video to a lesson, use the dropdown in the Selected Lesson box above.

6 Status Message

  • Ready — Nothing running.
  • Scanning… — A task is in progress; wait for it to finish.
  • Green — The last action completed successfully.
  • Red — Something went wrong; check the message and try again.

7 Tips

  • Stay signed in with an admin account so your changes save correctly.
  • Changes apply immediately for anyone using the site.
  • If you have a test site, try changes there first.

Admin Panel Changelog

Recent Changes

  • Admin panel created – Centralized dashboard for scanning lessons, assigning videos, and managing metadata.
  • Login mapped to Firebase Auth – Admin access now authenticated via Firebase email/password with optional “Remember Me”.
  • Backend created on Firebase – Firestore collections and Cloud Functions back the admin workflows and video tooling.
  • Removed WVSOM-specific references – Genericized UI and code paths so the platform is no longer institution‑specific.
  • Routes mapped back to Firebase – All lesson/video links wired so videos are served from Firebase Storage and can be managed via the admin panel.
  • Internal codebase reorganized – Cleaned up and documented project structure to match the current deployed behavior.
  • Responsive layouts – Admin and lesson UI dimensions tuned for both desktop and mobile‑sized viewports.
  • Instructions & Changelog modals added – Detailed admin help and this history view accessible from the header.
  • Lesson metadata editor – Per-lesson display name overrides and shared section display name overrides stored in Firestore.
  • Video assignment UI – Assign or update Firebase Storage videos per lesson through a dropdown.
  • Yellow screen handling – Toggle to remove/restore opening yellow-screen segments via Cloud Function or local fallback.
  • Segment link mapping – Automatic population of menuLink fields in srcArray using lesson menu buttons and currentSlide mappings.
  • OCR-based title detection – Cloud Function to detect and refine video segment titles using on-screen text.
  • Scan + status UX improvements – Clear “Missing / Has Video” badges, search/filter controls, and rich status messages while long tasks run.

To extend this changelog, edit the static list in admin.html under the #changelogModal section and redeploy.
