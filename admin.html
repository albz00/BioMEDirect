Admin Panel Instructions

1. Logging In

  • Use your admin Firebase email and password to log in.
  • Optionally check Remember Me to store your credentials locally on this device.

2. Overall Workflow

  1. Scan All Sections + Lessons – reads the main TextT central menu and discovers every lesson, section name, and lessonId.
  2. Refresh Available Videos – lists all `.mp4` files in Firebase Storage under `videos/`.
  3. Assign / Update Videos – for each lesson, choose a video from the dropdown and click Assign or Update.
  4. Optional: Map Segment Links – copies menu button labels into the `menuLink` field of matching `srcArray` segments.
  5. Optional: Detect Video Titles (OCR) – uses a Cloud Function to read video titles on-frame and refine `srcArray` segment titles.

3. Controls Section

  • Scan All Sections + Lessons (`scanBtn`)
    • Parses `TextT/CentralMenuT.html`.
    • Finds each lesson button and infers a lessonId from the HTML or filename.
    • For each lesson, looks up:
      • videoPaths/<lessonId> document (custom videoPath, yellowScreen flag).
      • lessonMetadata/<lessonId> document (display name override).
      • sectionNames/<originalSection> document (section display name override).
      • Video existence in Storage based on the resolved path.
    • Lessons with missing videos are listed first; then everything is alphabetized.
  • Refresh Available Videos (`refreshVideosBtn`)
    • Lists all `.mp4` files in the `videos/` folder in Firebase Storage.
    • Populates the dropdown for every lesson so you can assign or change videos.
  • Map Segment Links (`mapSegmentLinksBtn`)
    • For each lesson:
      • Reads the lesson HTML to find `menu` buttons (segment links).
      • Reads the corresponding JS file to find which `currentSlide` index each menu button jumps to.
      • Loads the video’s `srcArray` in the `lessons` collection.
      • Sets menuLink on `srcArray` segments where it is empty, using the labels from the HTML menu buttons.
    • Skips lessons if there are more menu buttons than segments or if the required files are missing.
  • Detect Video Titles (OCR) (`detectVideoTitlesBtn`)
    • For each lesson, calls the detectVideoTitles Cloud Function.
    • The function:
      • Analyzes video frames around each segment.
      • Uses OCR to detect on-screen titles.
      • Refines srcArray segment titles and, when possible, assigns menuLink labels.
    • Best used after a full scan and after videos are assigned.

4. Lessons Panel

  • Search – filters on lesson display name, lessonId, or HTML path (case-insensitive).
  • Filter Buttons
    • All – shows every discovered lesson.
    • Missing – shows only lessons where the resolved video path does not exist in Storage.
    • Has Video – shows only lessons with a confirmed video file.
  • Lesson Card Fields
    • Section – effective section display name. May be overridden for all lessons in a section.
    • Original – original section + button label from the TextT menu (never changes).
    • ID – canonical lessonId used as document key in Firestore.
    • Path – HTML lesson file path under TextT/.
    • Video – currently linked video path (from videoPaths or default pattern).
  • Section Name input
    • Edits the shared section display name for all lessons whose original section matches.
    • Stored in sectionNames/<originalSection>.displayName.
    • Clearing the field or resetting it to the original name removes the override.
  • Lesson Name input
    • Edits only this lesson’s display name.
    • Stored in lessonMetadata/<lessonId>.displayName.
    • Clearing the field or matching the original name removes the override.
  • Save Names button
    • Writes the appropriate overrides to Firestore.
    • Immediately refreshes the in-memory list and re-renders the UI.
    • Status text shows “Lesson metadata saved” when complete.
  • Video Select + Assign / Update
    • Dropdown lists all Storage videos discovered by Refresh Available Videos.
    • Click Assign or Update to:
      • Write videoPaths/<lessonId>.videoPath.
      • Verify that the selected file exists in Storage.
      • Update the lesson row to show the new path and status.
  • Remove yellow screen (adjust srcArray)
    • When checked:
      • Calls the detectYellowScreen Cloud Function with the video path.
      • Function analyzes opening frames and updates the video’s lessons/<videoFilename>.srcArray to skip yellow-screen segments.
      • Also records your preference in videoPaths/<lessonId>.yellowScreen.
    • When unchecked:
      • Restores the original srcArray (if originalSrcArray is available in the document).
    • If the Cloud Function is unavailable, a local “simple heuristic” fallback drops very short initial segments instead.

5. Available Videos Panel

  • Shows every `.mp4` Storage object under `videos/`.
  • This list is read-only and for reference; actual linking is done from each lesson card.

6. Status Indicator

  • Ready – idle; no background operations.
  • Scanning... – long-running tasks in progress (scan, mapping, OCR, yellow-screen handling).
  • Green styling – operation completed successfully.
  • Red styling – an error occurred; check the browser console for details.

7. Safety Notes

  • All writes go through Firestore security rules; make sure you are logged in as an authorized admin.
  • Changes are live for any deployed clients reading from the same Firestore project.
  • When in doubt, test on a staging project before using production credentials.

Admin Panel Changelog

Recent Changes

  • Admin panel created – Centralized dashboard for scanning lessons, assigning videos, and managing metadata.
  • Login mapped to Firebase Auth – Admin access now authenticated via Firebase email/password with optional “Remember Me”.
  • Backend created on Firebase – Firestore collections and Cloud Functions back the admin workflows and video tooling.
  • Removed WVSOM-specific references – Genericized UI and code paths so the platform is no longer institution‑specific.
  • Routes mapped back to Firebase – All lesson/video links wired so videos are served from Firebase Storage and can be managed via the admin panel.
  • Internal codebase reorganized – Cleaned up and documented project structure to match the current deployed behavior.
  • Responsive layouts – Admin and lesson UI dimensions tuned for both desktop and mobile‑sized viewports.
  • Instructions & Changelog modals added – Detailed admin help and this history view accessible from the header.
  • Lesson metadata editor – Per-lesson display name overrides and shared section display name overrides stored in Firestore.
  • Video assignment UI – Assign or update Firebase Storage videos per lesson through a dropdown.
  • Yellow screen handling – Toggle to remove/restore opening yellow-screen segments via Cloud Function or local fallback.
  • Segment link mapping – Automatic population of menuLink fields in srcArray using lesson menu buttons and currentSlide mappings.
  • OCR-based title detection – Cloud Function to detect and refine video segment titles using on-screen text.
  • Scan + status UX improvements – Clear “Missing / Has Video” badges, search/filter controls, and rich status messages while long tasks run.
