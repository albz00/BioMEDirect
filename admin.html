What’s in the Admin Panel

  • Scan all sections and lessons from the main TextT menu.
  • Assign and update Firebase Storage videos per lesson.
  • Clean up yellow-screen segments and refine srcArray.
  • Auto-map segment links and detect slide titles with OCR.
  • Rename sections and lessons without touching source HTML.

Full details and a complete history are available from the Instructions and Changelog buttons after you log in.

Admin Panel Instructions

                
BioME Control Panel — quick reference

                

                    
                    
                

            

            

                

                    
1 How it works

                    

                        Every lesson on the site is backed by one video in Firebase Storage and a
                        timeline (the list of chapter cards detected in that video).
                        This panel lets you upload videos, attach them to lessons, build the timeline,
                        and link each menu chapter to the exact moment it appears in the video.
                        Each lesson exists in two variants: Text (video with on-screen
                        text, IDs ending _t) and No-Text (IDs ending
                        _x). The Text / No-Text toggle switches which
                        variant every action targets.
                    

                


                

                    
2 Typical workflow

                    
    
                        
  1. Scan / Refresh — load every lesson and every Storage video.
    2. 
                        
  2. Pick the Text or No-Text variant in the sidebar.
    3. 
                        
  3. Upload Video (or select an existing one) and Assign it to a lesson. A file named name_x.mp4 is stored under videos/x/ automatically.
    4. 
                        
  4. Generate source — detect the yellow/green/red cards and build the timeline.
    5. 
                        
  5. Run AI green→menu mapping — match each green title card to a menu chapter.
    6. 
                        
  6. Save menu mapping, then Save all to persist the timeline.
    7. 
                    

                


                

                    
3 Header

                    
    
                        
  • 
                            Instructions
                            Instructions — opens this reference.
                        
    • 
                        
  • 
                            Changelog
                            Changelog — history of what has changed in the panel.
                        
    • 
                        
  • 
                            View Main Menu
                            View Main Menu — opens the live student-facing central menu in a new view.
                        
    • 
                        
  • 
                            Profile
                            Profile — shows your signed-in account and a Logout button.
                        
    • 
                        
  • 
                            Dev mode
                            Dev mode — toggles developer-only tools (raw detection tables, calibration inputs, Cursor export buttons). Off by default; leave it off for normal content work.
                        
    • 
                    

                


                

                    
4 Action bar

                    
    
                        
  • 
                            Scan / Refresh
                            Scan / Refresh — rebuilds the lesson list from the main menu and reloads the videos in Storage. Run this first; lessons missing a video sort to the top.
                        
    • 
                        
  • 
                            Upload Video
                            Upload Video — uploads one or more .mp4 files. A file ending in _x.mp4 is filed under videos/x/ (No-Text); anything else goes in videos/ (Text). If a single file's name matches a lesson ID it is auto-assigned.
                        
    • 
                        
  • 
                            Ready
                            Status — progress, success and error messages appear as a pop-up in the bottom-right corner so you can keep scrolling while a task runs.
                        
    • 
                    

                


                

                    
5 Sidebar (Lessons)

                    
    
                        
  • 
                            TextNo-Text
                            Text / No-Text toggle — chooses which video variant every action targets. Text = with on-screen text (_t); No-Text = without (_x). Your choice is remembered on this device.
                        
    • 
                        
  • 
                            Search lessons…
                            Search — filters the lesson tree by name as you type.
                        
    • 
                        
  • 
                            AllMissingHas Video
                            Filters — All shows every lesson; Missing shows only lessons without a video; Has Video shows only lessons that have one.
                        
    • 
                        
  • 
                            Missing Has Video
                            Status badge — each lesson shows whether a video is attached for the current variant.
                        
    • 
                        
  • 
                            ❮
                            Collapse arrow — hides the sidebar to give the editor more room.
                        
    • 
                    

                


                

                    
6 Lesson & Video card

                    
    
                        
  • 
                            Lesson Name
                            Lesson Name — display name shown in the menu. Edit it, then Save Lesson Name; the underlying source files are not touched.
                        
    • 
                        
  • 
                            Select a video…
                            Video dropdown — lists every Storage video. No-Text videos are prefixed with x/.
                        
    • 
                        
  • 
                            Assign Update
                            Assign / Update — links the selected video to the lesson (saved to the videoPaths override). Shows Assign when none is set, Update otherwise.
                        
    • 
                        
  • 
                            Use default path
                            Use default path (Dev) — clears the override so the lesson uses its default path (videos/<id>.mp4, or videos/x/<id>.mp4 for No-Text). Keeps the timeline.
                        
    • 
                        
  • 
                            Reset for reattach
                            Reset for reattach (Dev) — detaches the video and wipes all timeline/detection data so you can attach a fresh video. Chapter names are kept.
                        
    • 
                    

                


                

                    
7 Timeline editor

                    
    
                        
  • 
                            Generate source
                            Generate source — runs the three colour detectors on the assigned video (yellow = freeze, green = freeze + menu anchor, red = loop) and rebuilds the timeline rows.
                        
    • 
                        
  • 
                            Run AI green→menu mapping
                            Run AI green→menu mapping — uses GPT vision to read each green title card and match it to one of the lesson's chapter titles. Fills the mapping table below; it never changes the timeline.
                        
    • 
                        
  • 
                            Save menu mapping
                            Save menu mapping — saves the green→menu links. Every chapter with a selection becomes a live link that jumps to that timestamp during playback.
                        
    • 
                        
  • 
                            Save all
                            Save all — saves the edited timeline rows below to Firestore.
                        
    • 
                        
  • 
                            Wipe timeline
                            Wipe timeline — deletes all timeline + detection data for the lesson but keeps the assigned video, so you can Generate source again from a clean state.
                        
    • 
                        
  • 
                            Idle
                            AI status — shows the live state of the AI mapping run (Idle / running / done / error).
                        
    •

    • 
                        
  • type / cardCard colour: yellow, green, or red.
    •

    • 
                        
  • end (playback)When that content ends.
    • 
                        
  • flag DevManual marker used while diagnosing detection.
    • 
                        
  • lock DevPrevents a row's timing from being overwritten on regenerate.
    • 
                        
  • card / debug DevRaw detection source/confidence for that event.
    • 
                    

                


                

                    
8 Green → menu mapping table

                    
Appears after you run AI mapping. Each row is one detected green title card.

                    
    
                        
  • green #Which green card this is, in order.
    • 
                        
  • greenStartTimestamp where the green card begins.
    • 
                        
  • seek (post-card)The exact time a chapter click will jump to (just after the card).
    • 
                        
  • AI matched titleThe title GPT read from the card.
    • 
                        
  • menu chapterDropdown to confirm or override which menu chapter this green links to. Set — none — to leave that chapter at the start.
    • 
                        
  • conf.AI confidence in the match.
    • 
                        
  • reviewedOptional checkbox to mark a row as human-checked. Does not affect playback.
    • 
                        
  • reasonShort explanation of why the AI chose that chapter.
    • 
                    

                


                

                    
9 Available Videos

                    
Expand this card to browse Storage. Videos are split into two groups:

                    
    
                        
  • 
                            Text 12
                            Text — videos stored directly in videos/ (with on-screen text).
                        
    • 
                        
  • 
                            No-Text 3
                            No-Text — videos stored under videos/x/ (no on-screen text).
                        
    • 
                        
  • 
                            Preview
                            Preview — plays the video in a pop-up without assigning it.
                        
    • 
                        
  • 
                            Delete
                            Delete (Dev) — permanently removes the video and its timeline; clears any lesson using it.

10 Tips

                    
    
                        
  • Stay signed in with an admin account so your changes save.
    • 
                        
  • Changes apply immediately for everyone using the site.
    • 
                        
  • Set the Text / No-Text variant before uploading or assigning so the video lands in the right place.

    • 
                    
  • 
                        Internal codebase reorganized – Cleaned up and documented project structure to match the current deployed behavior.
                    
    • 
                    
  • 
                        Responsive layouts – Admin and lesson UI dimensions tuned for both desktop and mobile‑sized viewports.
                    
    • 
                    
  • 
                        Instructions & Changelog modals added – Detailed admin help and this history view accessible from the header.
                    
    • 
                    
  • 
                        Lesson metadata editor – Per-lesson display name overrides and shared section display name overrides stored in Firestore.
                    
    • 
                    
  • 
                        Video assignment UI – Assign or update Firebase Storage videos per lesson through a dropdown.
                    
    • 
                    
  • 
                        Yellow screen handling – Toggle to remove/restore opening yellow-screen segments via Cloud Function or local fallback.
                    
    • 
                    
  • 
                        Segment link mapping – Automatic population of menuLink fields in srcArray using lesson menu buttons and currentSlide mappings.
                    
    • 
                    
  • 
                        OCR-based title detection – Cloud Function to detect and refine video segment titles using on-screen text.
                    
    • 
                    
  •

    • 
                    
  • 
                        AI green→menu mapping – GPT vision reads each detected green title card and matches it to a menu chapter, building a green→menu seek map. Each mapped chapter becomes a live link that jumps to that timestamp; a runtime fix in masterUIcontrol.js now honors saved mappings.
                    
    • 
                    
  • 
                        Admin UI redesign – Bottom-right pop-up (toast) status that stays visible while scrolling, a unified non-dev action bar (Generate source, AI mapping, Save mapping, Save all, Wipe timeline), Dev mode off by default, and a cleaner minimal theme with the glow removed.

                        Text / No-Text dual-variant support – A Text/No-Text toggle re-keys every action to the _t or _x variant, with per-variant lesson IDs, paths, and video assignment.
